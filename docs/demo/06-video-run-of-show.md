# Video run-of-show — under 5 minutes

**Principle:** lead with the outcome, show one complete flow end to end, then show breadth (batch and review), and close with the platform depth that earns the 40%.

**Recording tips:**
- Record each script separately, the day before the deadline, and **cut the waiting time**: agent turns take 20 seconds to 2 minutes.
- Keep the "Thinking…" moments to about 1 second on screen.
- Use one voice, and no third-party music or copyrighted material.
- Filter the Project Intake list to today's demo records before recording.
- Use 110–125% browser zoom so the chat text is readable.
